FASE 3 DO PROJETO DA VINHERIA AGNELLO
A Vinheria Agnello está expandindo suas operações e deseja utilizar técnicas de ciência de dados para compreender melhor seus padrões de vendas. O objetivo é prever o sucesso de futuras vendas e visualizar indicadores estratégicos, apoiando a tomada de decisão.

 

Objetivo: Aplicar conceitos de Ciência de Dados e Aprendizado Supervisionado para construir um modelo preditivo simples e gerar insights visuais através de dashboards utilizando Power BI ou Tableau.

 

Etapas da Atividade

 

1. Defina a Base de Dados

A Vinheria Agnello está interessada em prever o sucesso de suas vendas com base em variáveis comerciais e operacionais.

Proponha e descreva pelo menos 8 colunas que farão parte da base de dados.
As colunas devem contemplar características relevantes sobre as vendas (produto, cliente, canal, região etc.).
Uma das colunas deve indicar se a venda teve sucesso ou não (será o rótulo da classificação).
Use a criatividade e o bom senso com base no contexto da Vinheria. Pense como um cientista de dados: quais dados fariam diferença para entender ou prever o sucesso das vendas?

 

2. Modelagem de Aprendizado Supervisionado

 

Escolha um algoritmo de classificação supervisionada (Árvore de Decisão, KNN etc.).
Explique os atributos de entrada escolhidos.
Descreva a lógica de separação entre treino e teste.
Apresente as métricas de avaliação esperadas (acurácia, precisão etc.).
 

3. Criação de Dashboard em Power BI ou Tableau

Utilize os dados simulados para criar um dashboard com pelo menos 3 visualizações.
Inclua filtros por período, produto e região.
Tente destacar visualmente padrões ou exceções nos dados.
 

4. Reflexão Final

Responda às seguintes perguntas:

Quais insights foram descobertos a partir dos dados?
Como a Vinheria poderia usar essa análise para tomar decisões estratégicas?
O modelo de classificação teve bom desempenho? Quais melhorias poderiam ser feitas?
