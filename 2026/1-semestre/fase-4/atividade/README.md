# Vinheria Agnello — Fase 4

Entrega acadêmica sobre persistência de dados aplicada ao controle de estoque.

## Conteúdo

- `android-estoque/`: aplicativo Kotlin, Jetpack Compose e Room.
- `csharp-estoque/`: aplicação console C# com persistência em JSON.
- `documentacao/relatorio-fase4.html`: fonte editável do relatório.
- `documentacao/roteiro-evidencias.md`: lista exata dos prints necessários.
- `documentacao/checklist-entrega.md`: conferência final.
- `NomeCompleto_RM_Fase4_Atividade.docx`: documento inicial com textos,
  códigos essenciais e espaços para inserir as evidências reais.

## Antes da entrega

1. Substitua os placeholders de nomes e RMs no documento.
2. Execute os dois projetos.
3. Tire os screenshots descritos no roteiro.
4. Insira cada imagem no espaço correspondente do DOCX.
5. Atualize as legendas e remova avisos de pendência.
6. Renomeie o DOCX conforme os dados reais do grupo.

Não declare como executada uma etapa sem anexar a evidência correspondente.
