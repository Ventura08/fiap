# Checklist final

## Código Android

- [ ] O projeto abre no Android Studio sem erro de sincronização.
- [ ] `./gradlew test` termina com sucesso.
- [ ] `./gradlew assembleDebug` termina com sucesso.
- [ ] Cadastro, listagem, edição e exclusão funcionam no emulador.
- [ ] Um produto permanece salvo após reiniciar o aplicativo.
- [ ] Todos os campos e mensagens estão legíveis.

## Código C#

- [ ] SDK .NET 8 ou superior instalado.
- [ ] `dotnet build` termina com sucesso.
- [ ] `dotnet run -- --self-test` termina com sucesso.
- [ ] O menu executa Create, Read, Update e Delete.
- [ ] `produtos.json` é criado e atualizado.
- [ ] Os dados permanecem após fechar e abrir o programa.

## Documento

- [ ] Nomes completos e RMs preenchidos.
- [ ] Nome da instituição, fase e projeto conferidos.
- [ ] Todas as figuras reais foram inseridas.
- [ ] Cada figura possui número, legenda e explicação.
- [ ] Avisos `[INSERIR PRINT REAL ...]` foram removidos.
- [ ] Não há afirmação de execução sem evidência.
- [ ] Código no documento corresponde ao código entregue.
- [ ] Ortografia e paginação revisadas.
- [ ] Referências oficiais mantidas.
- [ ] Arquivo renomeado para `NomeCompleto_RM_Fase4_Atividade.docx`.

## Empacotamento

- [ ] Confirmar na plataforma se somente o DOCX ou também os fontes são pedidos.
- [ ] Se necessário, criar ZIP com DOCX, `android-estoque/` e
      `csharp-estoque/`, sem pastas de build.
- [ ] Não incluir `.gradle/`, `build/`, `bin/`, `obj/`, `.idea/` ou credenciais.
- [ ] Abrir o arquivo final antes do upload.
